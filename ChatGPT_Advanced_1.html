01

이 안내와 로드맵 이용하기

모든 도구를 한 번에 익힐 필요는 없습니다. 현재 해결하려는 일에 필요한 도구 하나를 고르고 작은 요청부터 실행해 보세요.

도구 선택→문제 정리→질문·실행→확인·개선
  • 주차 선택: 로드맵에서 해당 주차를 선택해 요약과 사용 순서를 확인합니다.

04

AI에게 맡길 내 문제 찾기

“AI로 무엇을 할까?”가 막막하면, 반복하거나 시간이 오래 걸리는 일을 하나 떠올려 보세요.

다섯 가지 질문으로 정리하기

  1. 현재 상황나는 어떤 일을 하고 있나요?
  2. 어려움어느 단계에서 막히거나 시간이 오래 걸리나요?
  3. 입력 자료글·표·사진·규칙 중 무엇을 제공할 수 있나요?
  4. 원하는 결과요약·비교표·안내문·프로그램 중 무엇이 필요한가요?
  5. 완료 기준어떤 조건을 만족하면 잘된 결과인가요?

막연한 요청을 작업으로 바꾸기

처음 떠오른 문제
“수업 자료 정리가 오래 걸려요.”

실행할 수 있는 요청
“제공한 수업 자료를 성인 초보자가 복습할 수 있는 한 페이지 안내문으로 정리해 주세요. 핵심 개념과 사용 순서를 포함하고, 자료에 없는 내용은 넣지 마세요.”

막연한 불편→구체적인 작업→확인할 기준

한 번에 전체 업무를 맡기기보다 작은 단계부터 실행하고 확인합니다.

05

프롬프트를 구체화하는 다섯 가지 기준

다섯 항목은 요청을 점검하는 기준입니다. 모든 질문에 반드시 전부 넣어야 하는 공식은 아닙니다.

ROLE역할 · 어떤 관점으로?

AI에게 필요한 전문성이나 관점을 알려줍니다.

예: 성인 초보자를 가르치는 강사의 관점으로
GOAL목표 · 왜 필요한가?

이 결과를 통해 달성하려는 목적을 설명합니다.

예: 수강생이 수업 내용을 혼자 복습할 수 있도록
TASK작업 · 무엇을 할까?

AI가 수행할 일을 구체적인 동사로 적습니다.

예: 제공한 자료를 한 페이지 안내문으로 요약
RULE조건 · 무엇을 지킬까?

자료 범위, 분량, 출력 형식, 유지할 내용을 지정합니다.

예: 핵심 개념·사용 순서 포함, 자료에 없는 내용 제외
TONE말투 · 어떻게 표현할까?

읽는 사람에게 맞는 문장과 표현을 요청합니다.

예: 쉬운 한국어, 짧고 명확한 문장

예제 프롬프트 · 다섯 기준 연결하기

ROLE 성인 초보자를 가르치는 강사의 관점으로 답해 주세요. GOAL 수강생이 수업 내용을 혼자 복습할 수 있도록 돕고 싶습니다. TASK 아래에 제공한 수업 자료를 한 페이지 안내문으로 요약해 주세요. RULE 핵심 개념과 사용 순서를 포함하고, 자료에 없는 내용은 추가하지 마세요. 확인되지 않은 내용은 구분해 주세요. TONE 쉬운 한국어로 짧고 명확하게 작성해 주세요. [이 아래에 수업 자료를 붙여넣으세요.]

ROLE을 정해도 답변의 정확성이 보장되지는 않습니다. 답변에 포함된 사실·수치·근거를 확인하세요.

06

프롬프트가 어렵다면 AI에게 도움받기

처음부터 완벽하게 쓰려 하지 말고, 상황을 설명한 뒤 부족한 정보를 질문받습니다.

상황 전달→질문에 답하기→프롬프트 확인→실행·개선
  1. 문제를 설명합니다. 현재 상황·어려움·원하는 결과를 적습니다.
  2. 부족한 정보를 질문받습니다. AI가 추측한 조건이 있으면 바로잡습니다.
  3. 프롬프트를 검토합니다. 내 목적과 자료 범위가 맞는지 확인합니다.
  4. 실행하고 고칩니다. 같은 대화 또는 새 대화에서 사용한 뒤 실제 결과를 보고 요청을 보완합니다.

예제 프롬프트 · 작성 도움받기

내가 해결하려는 문제는 [문제]입니다. 현재 상황은 [상황]이고, 원하는 결과는 [결과]입니다. 사용할 수 있는 자료는 [자료]입니다. 먼저 프롬프트 작성에 필요한 부족한 정보를 질문해 주세요. 내 답변을 바탕으로 ROLE, GOAL, TASK, RULE, TONE을 고려한 실행용 프롬프트를 작성해 주세요. 확인되지 않은 조건은 임의로 정하지 마세요. 완성된 프롬프트와 함께 결과를 확인할 기준도 알려 주세요.

예제 프롬프트 · 결과가 아쉬울 때

현재 결과에서 [아쉬운 부분]이 내 의도와 다릅니다. [원하는 방향]으로 수정해 주세요. [유지할 부분]은 그대로 유지해 주세요. 판단에 필요한 정보가 부족하면 먼저 질문해 주세요.

02AI와 대화형 AI 알아보기

AI(인공지능)는 데이터를 바탕으로 분류·예측·생성 등의 작업을 수행하는 기술입니다. 대화형 AI는 질문이나 요청을 대화로 전달하고 답변을 받는 방식으로 활용합니다.

활용 예시

  • 어려운 개념을 쉬운 말로 설명받습니다.
  • 긴 글을 요약하거나 안내문을 작성합니다.
  • 아이디어를 얻고, 해야 할 일을 정리합니다.

ℹ️ 이용 시 주의사항
AI의 답변은 틀릴 수 있으므로 중요한 내용은 확인합니다.
개인 정보나 민감한 자료는 입력하기 전에 공개해도 되는 내용인지 살펴봅니다.

03대화형 AI 서비스에서 간단한 질문으로 시작하기

ChatGPT 🔗, Gemini 🔗, Claude 🔗, Grok 🔗 등의 생성형 AI 서비스에서 질문하고 글을 작성·정리해 볼 수 있습니다.

서비스별 기능과 무료 이용 범위는 계정이나 제공 조건에 따라 다를 수 있습니다.

사용 순서

  1. 사용할 서비스에 접속하고 필요한 계정으로 로그인합니다. 수업 준비물인 Google 계정도 준비합니다.
  2. 입력창에 궁금한 내용을 적고 질문을 보냅니다.
  3. 답변이 어렵다면 “더 쉬운 말로 설명해줘”처럼 요청을 이어갑니다.
  4. 중요한 사실은 원자료나 다른 출처와 비교해 확인합니다.

예제 프롬프트

대화형 AI가 무엇인지 처음 배우는 사람에게 쉬운 말로 설명해줘. 일상생활에서 활용할 수 있는 예시 3개도 알려줘.
기억할 점
다양한 AI 플랫폼을 사용해 보고, 내 목적에 더 잘 맞는 모델이나 기능이 나오면 다른 플랫폼도 활용해 봅시다.
한 플랫폼에만 익숙해지기보다, 필요에 따라 도구를 바꿔 사용할 수 있는 유연한 태도가 중요합니다.

01생성형 AI 알아보기

생성형 AI는 사용자의 요청에 따라 글·이미지·표·코드 등의 결과물을 만드는 AI입니다.
ChatGPT와 Gemini로 질문하고 내용을 작성·정리할 수 있습니다.

사용 순서

  1. ChatGPT 🔗 또는 Gemini 🔗에 접속합니다.
  2. 화면 오른쪽 상단의 로그인 버튼 → Google로 계속 🔍을 선택해 Google 계정으로 로그인합니다.
  3. 화면 아래쪽 입력창에 질문을 작성하고 전송 버튼 🔍을 누릅니다.

처음 해볼 질문

생성형 AI가 무엇인지 일상생활의 활용 예시 3개와 함께 쉽게 설명해줘.

02프롬프트 작성하기

프롬프트는 AI에게 전달하는 질문이나 지시입니다. 목적·대상·조건·결과 형식을 함께 설명합니다.

  • 목적: 수업 복습용 안내문 작성
  • 대상: 생성형 AI를 처음 배우는 성인
  • 조건: 쉬운 표현, 생활 속 예시 3개
  • 형식: 짧은 설명과 핵심 정리표

요청 예시

생성형 AI를 처음 배우는 성인을 위한 수업 복습용 안내문을 작성해줘. 쉬운 표현으로 생활 속 활용 예시 3개를 넣고, 마지막에 핵심 내용을 표로 정리해줘.

답변 개선하기

첫 요청 → 답변 확인 → 조건 추가 → 수정 결과 확인

같은 대화에서 “전문 용어를 줄여줘”처럼 요청을 이어갑니다.

복잡한 작업은 다음처럼 나눠 진행합니다.
조사 → 정리 → 결과물 작성

03조사에서 발표자료까지

심층 리서치는 여러 자료를 조사해 출처와 함께 정리하는 기능입니다.
Canvas는 결과물을 작성하고 수정하는 작업 공간입니다.

① ChatGPT 🔗에서 조사하기

  1. 입력창 왼쪽의 ＋ 버튼 🔍을 누릅니다.
  2. 펼쳐진 메뉴에서 심층 리서치 🔍를 선택합니다.
  3. 주제·조사 범위·결과 형식을 입력하고 전송합니다.
  4. 완성된 보고서의 출처 표시 🔍를 선택해 원문을 확인합니다.

예제 프롬프트

한국 성인의 일상생활 속 생성형 AI 활용 사례를 조사해줘. 최근 1년 자료를 중심으로 사례 5개와 각 출처를 정리해줘.

② Gemini 🔗에서 발표자료 만들기

  1. 확인한 조사 결과를 Gemini 입력창에 붙여넣습니다.
  2. 입력창 주변 도구 메뉴의 Canvas 🔍를 선택합니다.
  3. 발표 시간·대상·슬라이드 수를 적어 요청합니다.
  4. Canvas 작업 화면 🔍에서 내용을 확인하고 수정을 요청합니다.
  5. 내보내기 메뉴 🔍에서 제공되는 저장·전환 옵션을 선택합니다.

예제 프롬프트

위 조사 결과를 바탕으로 AI 초보자를 위한 5분 발표자료를 만들어줘. 표지와 결론을 포함해 6장으로 구성하고, 각 장에는 핵심 내용 3개 이내로 넣어줘.
기억할 점
사실·출처·조사 시점을 확인하고 활용합니다. 버튼 위치와 제공 기능은 계정·업데이트에 따라 달라질 수 있습니다.

01이미지 생성 조건 정하기

이미지 요청에는 대상·배경·스타일·구도·세부 조건을 넣습니다. 결과를 확인하면서 조건을 보완하고, 바꿀 부분과 유지할 부분을 구분합니다.

사용 순서

  1. 만들 대상과 사용 목적을 정합니다.
  2. 배경·스타일·구도와 필요한 세부 조건을 적습니다.
  3. 결과를 보고 수정할 부분을 구체적으로 설명합니다.

예제 프롬프트

태풍을 설명하는 일기예보용 이미지를 만들어줘. 바다 위 태풍과 이동 경로가 보이도록 구성하고, 수업 자료에 사용할 수 있게 주요 요소를 명확하게 표현해줘.

02Google AI Studio에서 생성하고 수정하기

Google AI Studio에서 이미지 생성 모델을 선택하고 준비한 프롬프트를 입력합니다. 모델에 따라 구도·글자·세부 표현이 달라질 수 있습니다.

사용 순서

  1. Google AI Studio 🔗에 접속해 이미지 생성 모델 🔍을 선택합니다.
  2. 프롬프트를 입력하고 결과를 확인 🔍합니다.
  3. 부족한 조건을 추가해 다시 요청합니다.

모델 선택 → 프롬프트 입력 → 생성 → 확인·수정

03Arena에서 결과 비교하기

같은 요청으로 생성된 두 이미지의 요청 반영·구도·글자 정확성·세부 표현을 비교합니다. 수업 자료의 Battle Mode에서는 평가 후 모델 이름을 확인합니다.

사용 순서

  1. Arena 🔗에 로그인 후 이미지 비교 화면과 Battle Mode 🔍를 확인합니다.
  2. 같은 프롬프트로 두 결과를 생성 🔍합니다.
  3. 결과를 비교·평가한 뒤 모델 이름을 확인 🔍합니다.

같은 요청 → 두 결과 비교 → 평가 → 모델 확인

기억할 점
어떤 모델을 사용했는지를 통해 각각의 모델의 특징을 확인합니다. 또한 모델 이름만으로 우열을 정하기보다, 내가 요청한 조건이 얼마나 반영되었는지 비교합니다.

01목적과 규칙을 프롬프트로 정리하기

바이브 코딩은 원하는 기능과 모습을 말로 설명하고, AI가 만든 코드를 실행·수정하며 프로그램을 완성하는 방식입니다.
코딩으로 만들 수 있는 프로그램은 여러가지가 있지만, 목적과 설계가 뚜렷한 프로그램으로는 대표적으로 게임이 있습니다.
게임 제작 바이브코딩 실습에서는 준비·진행·특별 규칙·승리 조건을 나누어 작성합니다.

사용 순서

  1. 사용자 수와 시작 화면을 정합니다.
  2. 차례·행동·이동·특별 규칙을 설명합니다.
  3. 승리·종료 조건을 정하고 빠진 조건을 AI에게 질문받습니다.

예제 프롬프트 (직접 설명)

두 사람이 같은 화면에서 번갈아 두는 턴제 오목 게임을 만들어줘.

준비: 15×15 교차점의 빈 바둑판을 보여줘. 첫 번째 사람은 흑돌, 두 번째 사람은 백돌을 사용하고 흑돌부터 시작해. 현재 차례와 다시 시작 버튼을 표시해.
진행: 자기 차례에 빈 교차점을 클릭하거나 터치하면 돌을 하나 놓고 상대 차례로 바꿔줘. 이미 돌이 있는 곳을 누르면 돌과 차례를 그대로 유지해.
특별 규칙: 이번 실습에서는 금수와 시간 제한을 적용하지 않고, 흑돌과 백돌에 같은 규칙을 적용해. 돌을 놓은 직후 승리 여부를 먼저 확인하고, 게임이 끝나면 추가로 돌을 놓지 못하게 해.
승리 조건: 가로·세로·대각선 중 어느 방향이든 자기 돌이 5개 이상 연속되면 승리해. 승자가 없이 바둑판이 가득 차면 무승부로 처리해. 다시 시작을 누르면 돌과 결과를 지우고 흑돌 차례로 돌아가게 해.

예제 프롬프트 (AI에게 프롬프트 문의)

두 사람이 번갈아 하는 오목 게임을 만들고 싶은데, AI에게 어떻게 설명해야 할지 모르겠어. 코딩도 잘 몰라.

어떤 규칙과 기능을 정해야 하는지 쉬운 말로 물어봐 줘. 내가 답하면 그 내용을 정리해서 Google AI Studio에 그대로 넣을 수 있는 프롬프트를 만들어줘.

목적이 다른 프로그램도 설계와 규칙, 동작 등을 규격화하여 Google AI Studio 등의 바이브 코딩 가능한 플랫폼에서 바이브 코딩을 진행할 수 있습니다.

02Google AI Studio에서 제작하고 실행하기

앱 제작 화면에 프롬프트를 입력하고, 생성된 프로그램을 미리보기에서 실행합니다. 게임 이름보다 구체적인 규칙과 동작을 설명합니다.

사용 순서

  1. Google AI Studio 🔗의 Build 또는 New app 🔍을 엽니다.
  2. 제작 프롬프트를 입력 🔍해 생성합니다.
  3. 미리보기 🔍에서 버튼·차례·이동·승리 판정을 확인합니다.

규칙 설명 → 생성 → 실행

03문제를 설명하고 반복 수정하기

수정 요청에는 문제가 발생한 상황·현재 결과·원하는 결과를 함께 적습니다. 문제를 하나씩 수정하고 기존 규칙도 다시 확인합니다.

사용 순서

  1. 문제가 발생한 동작을 다시 실행합니다.
  2. 현재 결과와 원하는 동작을 비교해 설명하여 수정 요청 🔍합니다.
  3. 수정 후 같은 상황과 다른 규칙을 확인합니다.

예제 프롬프트

만든 오목 게임에서 이미 돌이 있는 곳을 누르면 돌은 안 놓이는데 상대 차례로 넘어가. 잘못 누른 건데 내 차례가 끝나 버려.

돌이 있는 곳을 눌러도 내 차례가 그대로 남게 고쳐줘. 다른 게임 규칙은 그대로 유지해줘.

문제 확인 → 수정 요청 → 재실행

기억할 점
AI가 만든 프로그램은 직접 실행해 확인합니다. 요청한 규칙이 빠졌거나 다르게 작동하면 구체적으로 수정합니다.
구체적인 규칙을 설명하기 어렵다면, AI에게 프롬프트를 문의하여 나온 결과를 활용합시다.
표, 목록, 단계별 설명 등 원하는 결과의 형태도 함께 요청하면, 활용하기 좋은 답변을 받을 수 있습니다.

01문서와 발표자료로 활용하기

Gemini의 Canvas 기능을 이용해 내용을 작성·정리하고 수정 요청을 이어갑니다. 목적에 맞게 제목·구성·분량을 조정한 뒤 결과를 활용합니다.
Canvas 기능을 사용하기 위해서는 로그인이 필요합니다.

사용 순서

  1. Gemini 🔗의 입력창 좌측의 + 버튼을 눌러 Canvas 기능을 활성화 한 뒤 🔍, 생성하고자 하는 자료와 원하는 형식을 입력합니다.
  2. 생성된 내용 🔍의 사실·구성·분량을 확인합니다.
  3. 수정 요청 후 제공되는 내보내기 옵션을 확인 🔍합니다.

예제 프롬프트 (문서 - Docs 생성)

가상의 작은 매장에서 사용할 판매 기록 안내문을 만들어줘. 처음 일하는 직원도 이해할 수 있게 쉬운 말로 작성해줘. 기록 항목은 판매일, 상품명, 수량, 단가, 판매금액으로 하고, 제목·기록 방법·주의할 점으로 나눠줘. 판매금액은 수량×단가로 계산한다는 설명과 가상의 기록 예시 1개도 넣어줘.

예제 프롬프트 (CSV - Sheets 생성)

가상의 작은 매장 판매 기록을 연습용 CSV 데이터 20행으로 만들어줘. 열은 판매일, 상품명, 수량, 단가, 판매금액으로 구성해줘. 상품명은 한글로 쓰고, 판매금액은 수량×단가로 계산해줘. 숫자 안에는 쉼표를 넣지 마.

예제 프롬프트 (PPT - Slides 생성)

앞에서 만든 판매 기록을 활용해 직원 교육용 발표자료 3장을 만들어줘. 판매 기록이 필요한 이유, 기록 방법, 주의할 점 순서로 구성하고, 가상 데이터 일부를 예시로 넣어줘.

02더미 데이터를 생성하고 확인하기

더미 데이터는 연습용 가짜 데이터입니다. 행 개수·열 이름·값의 범위·출력 형식을 지정합니다. CSV는 표 데이터를 담는 텍스트 형식입니다.
유니코드는 컴퓨터가 한글·영어 등 여러 언어의 글자를 구별할 수 있도록 정한 공통 약속입니다.
UTF-8은 이 약속에 따라 글자를 파일에 저장하는 방법입니다.
CSV 파일을 저장한 방식과 프로그램이 읽는 방식이 다르면 한글이 깨질 수 있습니다. UTF-8로 저장한 파일은 불러올 때도 UTF-8을 선택합니다.

사용 순서

  1. AI에 데이터 조건과 CSV 형식을 요청 🔍합니다.
  2. Excel이나 Sheets로 옮겨 표로 확인 🔍합니다.
  3. 행·열 개수와 한글·숫자를 검토합니다. 한글이 깨지면 읽는 문자 방식이 UTF-8 🔍인지 확인합니다.

예제 프롬프트

앞에서 정한 판매 기록 항목으로 연습용 가상 데이터 20행을 만들어줘. 열은 판매일, 상품명, 수량, 단가, 판매금액으로 하고 CSV 형식으로 보여줘. 상품명은 한글로, 수량은 1~5개, 단가는 1000~20000원으로 해줘. 판매금액은 수량×단가로 계산하고, 숫자 안에는 쉼표를 넣지 마.

조건 지정 → 생성 → 표로 확인 → 오류 수정

03작업 도구와 AI 실험 기능 살펴보기

Google Workspace는 구글의 문서 작성·협업 도구 모음입니다. Docs로 문서, Sheets로 표와 데이터, Slides로 발표자료를 만들 수 있습니다.
각 도구 안의 Gemini AI 기능은 이용 중인 요금제와 계정에 따라 제공 범위가 달라집니다. 개인 Google 계정은 Workspace Experiments에 참여해 일부 실험 기능을 먼저 사용해 볼 수도 있습니다. 다만 참여 조건과 지원 국가·언어에 따라 이용 가능 여부가 달라집니다.
Google Labs에서는 이 밖에도 다양한 AI 도구와 실험 기능을 살펴볼 수 있습니다.

사용 순서

  1. Google Workspace 🔗에서 사용할 데이터 유형(문서·표·발표 도구(PPT))에 따라 Docs 🔗, Sheets 🔗, Slides 🔗의 플랫폼을 정합니다.
  2. 선택한 플랫폼에서 Gemini를 비롯한 AI 기능을 사용하기 위해 Workspace Experiments 🔗에서 실험 기능 사용에 대한 동의 🔍를 진행합니다.
  3. 동의 후 각 플랫폼에서 AI 기능을 활용해봅니다. 동일한 사용 방법으로는 우측 상단의 문서 플랫폼 내 Gemini 채팅 🔍이 있습니다.

Workspace Experiments 참여는 이용 조건을 충족하는 개인 Google 계정을 기준으로 합니다. 동의 후에도 계정과 기능별 제공 상황에 따라 사용 가능한 기능이 달라질 수 있습니다.

앞에서 만든 CSV를 Sheets로 불러온 뒤, Gemini 채팅에서 다음처럼 요청합니다.

예제 프롬프트

이 판매표에서 상품별 판매수량과 판매금액을 합계로 정리해줘. 판매금액이 가장 큰 상품도 알려줘.

ℹ️ 실험 기능 이용 안내
실험 기능은 서비스 운영 정책에 따라 참여 조건, 제공 기능, 이용 가능 기간이 변경되거나 제공이 종료될 수 있습니다. 사용 전에 해당 서비스의 최신 안내를 확인해 주세요.

ℹ️ 데이터 전송 및 민감 정보 주의
Workspace Experiments에 동의하고 실험 기능을 사용하면 입력한 질문, 참조한 문서 내용, 생성 결과와 피드백 등이 Google로 전송·수집되어 서비스와 AI 기술 개선에 사용될 수 있으며, 검토 담당자가 확인할 수도 있습니다.
개인정보·비밀번호·비공개 업무 자료 등 민감한 정보를 입력하거나 AI가 참조할 자료에 포함하지 않도록 각별히 주의하고, 실습에는 가상의 자료를 사용합니다.

01주제에 맞는 자료 준비하기

사용 순서

  1. 새 노트북을 만들고 주제가 드러나는 이름을 정합니다.
  2. PDF·Drive 문서·웹페이지·텍스트 등을 소스로 추가합니다.
  3. 등록된 자료와 질문에 사용할 선택 범위를 확인합니다.

주제 정하기 → 자료 추가 → 범위 선택

02선택한 자료 안에서 질문하기

사용 순서
