AI에게 맡길 내 문제 찾기

“AI로 무엇을 할까?”가 막막하면, 반복하거나 시간이 오래 걸리는 일을 하나 떠올려 보세요.

다섯 가지 질문으로 정리하기

  1. 현재 상황나는 어떤 일을 하고 있나요?
  2. 어려움어느 단계에서 막히거나 시간이 오래 걸리나요?
  3. 입력 자료글·표·사진·규칙 중 무엇을 제공할 수 있나요?
  4. 원하는 결과요약·비교표·안내문·프로그램 중 무엇이 필요한가요?
  5. 완료 기준어떤 조건을 만족하면 잘된 결과인가요?

막연한 요청을 작업으로 바꾸기

처음 떠오른 문제
“수업 자료 정리가 오래 걸려요.”

실행할 수 있는 요청
“제공한 수업 자료를 성인 초보자가 복습할 수 있는 한 페이지 안내문으로 정리해 주세요. 핵심 개념과 사용 순서를 포함하고, 자료에 없는 내용은 넣지 마세요.”

막연한 불편→구체적인 작업→확인할 기준

한 번에 전체 업무를 맡기기보다 작은 단계부터 실행하고 확인합니다.

05

프롬프트를 구체화하는 다섯 가지 기준

다섯 항목은 요청을 점검하는 기준입니다. 모든 질문에 반드시 전부 넣어야 하는 공식은 아닙니다.

ROLE역할 · 어떤 관점으로?

AI에게 필요한 전문성이나 관점을 알려줍니다.

예: 성인 초보자를 가르치는 강사의 관점으로
GOAL목표 · 왜 필요한가?

이 결과를 통해 달성하려는 목적을 설명합니다.

예: 수강생이 수업 내용을 혼자 복습할 수 있도록
TASK작업 · 무엇을 할까?

AI가 수행할 일을 구체적인 동사로 적습니다.

예: 제공한 자료를 한 페이지 안내문으로 요약
RULE조건 · 무엇을 지킬까?

자료 범위, 분량, 출력 형식, 유지할 내용을 지정합니다.

예: 핵심 개념·사용 순서 포함, 자료에 없는 내용 제외
TONE말투 · 어떻게 표현할까?

읽는 사람에게 맞는 문장과 표현을 요청합니다.

예: 쉬운 한국어, 짧고 명확한 문장

예제 프롬프트 · 다섯 기준 연결하기

ROLE 성인 초보자를 가르치는 강사의 관점으로 답해 주세요. GOAL 수강생이 수업 내용을 혼자 복습할 수 있도록 돕고 싶습니다. TASK 아래에 제공한 수업 자료를 한 페이지 안내문으로 요약해 주세요. RULE 핵심 개념과 사용 순서를 포함하고, 자료에 없는 내용은 추가하지 마세요. 확인되지 않은 내용은 구분해 주세요. TONE 쉬운 한국어로 짧고 명확하게 작성해 주세요. [이 아래에 수업 자료를 붙여넣으세요.]

ROLE을 정해도 답변의 정확성이 보장되지는 않습니다. 답변에 포함된 사실·수치·근거를 확인하세요.

06

프롬프트가 어렵다면 AI에게 도움받기

처음부터 완벽하게 쓰려 하지 말고, 상황을 설명한 뒤 부족한 정보를 질문받습니다.

상황 전달→질문에 답하기→프롬프트 확인→실행·개선
  1. 문제를 설명합니다. 현재 상황·어려움·원하는 결과를 적습니다.
  2. 부족한 정보를 질문받습니다. AI가 추측한 조건이 있으면 바로잡습니다.
  3. 프롬프트를 검토합니다. 내 목적과 자료 범위가 맞는지 확인합니다.
  4. 실행하고 고칩니다. 같은 대화 또는 새 대화에서 사용한 뒤 실제 결과를 보고 요청을 보완합니다.

예제 프롬프트 · 작성 도움받기

내가 해결하려는 문제는 [문제]입니다. 현재 상황은 [상황]이고, 원하는 결과는 [결과]입니다. 사용할 수 있는 자료는 [자료]입니다. 먼저 프롬프트 작성에 필요한 부족한 정보를 질문해 주세요. 내 답변을 바탕으로 ROLE, GOAL, TASK, RULE, TONE을 고려한 실행용 프롬프트를 작성해 주세요. 확인되지 않은 조건은 임의로 정하지 마세요. 완성된 프롬프트와 함께 결과를 확인할 기준도 알려 주세요.

예제 프롬프트 · 결과가 아쉬울 때

현재 결과에서 [아쉬운 부분]이 내 의도와 다릅니다. [원하는 방향]으로 수정해 주세요. [유지할 부분]은 그대로 유지해 주세요. 판단에 필요한 정보가 부족하면 먼저 질문해 주세요.

01목적과 규칙을 프롬프트로 정리하기

바이브 코딩은 원하는 기능과 모습을 말로 설명하고, AI가 만든 코드를 실행·수정하며 프로그램을 완성하는 방식입니다.
코딩으로 만들 수 있는 프로그램은 여러가지가 있지만, 목적과 설계가 뚜렷한 프로그램으로는 대표적으로 게임이 있습니다.
게임 제작 바이브코딩 실습에서는 준비·진행·특별 규칙·승리 조건을 나누어 작성합니다.

사용 순서

  1. 사용자 수와 시작 화면을 정합니다.
  2. 차례·행동·이동·특별 규칙을 설명합니다.
  3. 승리·종료 조건을 정하고 빠진 조건을 AI에게 질문받습니다.

예제 프롬프트 (직접 설명)

두 사람이 같은 화면에서 번갈아 두는 턴제 오목 게임을 만들어줘.

준비: 15×15 교차점의 빈 바둑판을 보여줘. 첫 번째 사람은 흑돌, 두 번째 사람은 백돌을 사용하고 흑돌부터 시작해. 현재 차례와 다시 시작 버튼을 표시해.
진행: 자기 차례에 빈 교차점을 클릭하거나 터치하면 돌을 하나 놓고 상대 차례로 바꿔줘. 이미 돌이 있는 곳을 누르면 돌과 차례를 그대로 유지해.
특별 규칙: 이번 실습에서는 금수와 시간 제한을 적용하지 않고, 흑돌과 백돌에 같은 규칙을 적용해. 돌을 놓은 직후 승리 여부를 먼저 확인하고, 게임이 끝나면 추가로 돌을 놓지 못하게 해.
승리 조건: 가로·세로·대각선 중 어느 방향이든 자기 돌이 5개 이상 연속되면 승리해. 승자가 없이 바둑판이 가득 차면 무승부로 처리해. 다시 시작을 누르면 돌과 결과를 지우고 흑돌 차례로 돌아가게 해.

두 사람이 번갈아 하는 오목 게임을 만들고 싶은데, AI에게 어떻게 설명해야 할지 모르겠어. 코딩도 잘 몰라.

02더미 데이터를 생성하고 확인하기

더미 데이터는 연습용 가짜 데이터입니다. 행 개수·열 이름·값의 범위·출력 형식을 지정합니다. CSV는 표 데이터를 담는 텍스트 형식입니다.
유니코드는 컴퓨터가 한글·영어 등 여러 언어의 글자를 구별할 수 있도록 정한 공통 약속입니다.
UTF-8은 이 약속에 따라 글자를 파일에 저장하는 방법입니다.
CSV 파일을 저장한 방식과 프로그램이 읽는 방식이 다르면 한글이 깨질 수 있습니다. UTF-8로 저장한 파일은 불러올 때도 UTF-8을 선택합니다.

사용 순서

  1. Gemini 🔗에 데이터 조건과 CSV 형식을 요청 🔍합니다.
  2. Excel이나 Sheets로 옮겨 표로 확인 🔍합니다.
  3. 행·열 개수와 한글·숫자를 검토합니다. 한글이 깨지면 읽는 문자 방식이 UTF-8 🔍인지 확인합니다.

  2. A2:A6의 ‘완료’ 개수를 셀 가장 간단한 일반 함수를 요청합니다.
  3. 추천 수식의 범위를 확인하고 B9에 적용합니다.

A2:A6에서 “완료” 항목의 개수를 세고 싶어. AI 함수 대신 쓸 가장 간단한 함수를 알려줘. 내 셀 위치에 맞는 수식도 만들어줘.

예제 수식 · B9에 입력

=COUNTIF(A2:A6,"완료")

대표 함수의 목적

  • SUM: 합계 / AVERAGE: 평균
  • COUNT: 숫자가 있는 셀 개수 / COUNTA: 내용이 있는 셀 개수
  • IF: 조건에 따라 구분 / COUNTIF: 조건에 맞는 개수 / SUMIF: 조건에 맞는 값 합계

B2:B4에 1000, 2000, 3000을 입력하면 =SUM(B2:B4)의 결과는 6000입니다. 수식 오류가 나면 셀 위치와 오류 메시지를 함께 알려주고, 수정 결과도 검토합니다.

01AI Agent 이해하기

답변에서 실제 작업으로

AI Agent는 목표를 전달받고 도구를 사용해 여러 단계의 작업을 이어갈 수 있는 AI입니다. 일반 대화에서 만드는 방법을 설명받았다면, Cursor의 Agent에는 이 폴더에 계산기를 만들어 달라고 요청합니다.

Cursor는 코드 작성·파일 관리·실행을 돕는 작업 환경인 IDE에 AI 기능을 더한 도구입니다. 무료 이용도 요청 한도가 있으므로 계정의 이용 가능 범위를 확인합니다.

02Cursor 설치와 작업 폴더 준비

  1. Cursor 공식 다운로드 🔗에서 내 PC에 맞는 Windows 설치 파일을 받고 설치 파일을 실행합니다. 🔍
  2. 설치 중 PATH 또는 환경변수 관련 항목 🔍이 보이면 선택 상태를 확인합니다. PATH는 Windows가 프로그램의 실행 위치를 찾도록 알려주는 설정입니다. 항목이 없으면 자동 적용 여부를 확인합니다.
  3. 브라우저에서 로그인 🔍을 마치고 Cursor로 돌아와 계정 연결을 확인합니다.
  4. 문서 → AI_실습 → 계산기 순서로 빈 연습 폴더를 만듭니다.
  5. File → Open Folder에서 계산기 폴더를 열고 🔍 파일 영역의 폴더 이름을 확인합니다.

중요한 업무 자료 폴더 대신 빈 연습 폴더를 사용합니다. 폴더 지정만으로 모든 접근이 차단되지는 않으므로 작업할 파일과 명령도 확인합니다.

07AI 서비스 소개

AI Agent는 목표에 필요한 작업을 단계적으로 진행할 수 있는 AI 기능입니다.

  • ChatGPT 🔗 Work: 계획을 세우고 자료·문서 등 여러 단계 작업 진행
  • Gemini 🔗 Task: 요청을 여러 단계로 처리하고 파일 등 결과 생성
  • Claude 🔗 Cowork: 자료와 파일을 읽고 여러 단계의 업무를 처리하며 결과물 생성

소개한 AI Agent 기능을 사용하려면 각 서비스에서 해당 기능을 지원하는 유료 플랜을 구독해야 합니다.

기억할 점
Agent 수보다 역할·순서·결과 전달·마지막 확인이 중요합니다. 수정할 부분과 유지할 부분을 함께 말합니다.

01Google Calendar 간단 요약 및 이번 실습 목표

Google Calendar 🔗는 수업·약속·업무를 날짜와 시간에 맞춰 기록하는 일정 도구입니다. AI가 만든 일주일 가상 일정을 CSV로 저장하고 한 번에 가져옵니다.

작성 → 검수 → 가져오기 → 실제 일정 확인

지난주처럼 작성과 검수를 나누어 요청할 수 있습니다. 마지막 날짜·시간·중복 확인은 직접 합니다. 실제 개인정보 대신 가상 일정을 사용합니다.

02일정 하나 만들고 실습용 캘린더 준비하기

  1. 날짜·빈 시간을 선택하고 제목·시작 및 종료 시간·캘린더를 확인합니다.
  2. 필요하면 장소·설명을 넣고 저장합니다. 일정 만들기 화면 🔍
  3. 수정할 때는 일정 선택 → 연필 모양 수정 → 내용 변경 → 저장 순서로 진행합니다.
  4. 웹브라우저에서 왼쪽 “다른 캘린더” 옆 ＋ → “새 캘린더 만들기”를 선택합니다.
  5. “AI 실습” 또는 “CSV 일정 실습” 등 이름을 입력하고 만듭니다. 새 캘린더 만들기 🔍

가상 일정이 실제 약속과 섞이지 않도록 별도 실습용 캘린더를 사용합니다.

03가져오기·내보내기와 Calendar용 CSV

메뉴 이름은 Google Calendar를 기준으로 생각합니다.

  • 가져오기: 외부 파일 → Calendar. 이번에 직접 실습합니다.
  • 내보내기: Calendar → 외부 파일(ICS). 이번에는 의미만 확인합니다.

CSV는 첫 줄이 열 이름, 다음 줄부터 데이터인 텍스트 파일입니다. 기본 구조와 UTF-8은 5주차를 참고합니다. 이번에는 Calendar가 인식하는 영어 헤더를 그대로 씁니다.

  • Subject: 일정 제목 · 필수
  • Start Date: 시작 날짜 · 필수 · 10/29/2026
  • Start Time / End Time: 시작·종료 시간 · 10:00 AM / 11:00 AM
  • Description: 설명 · 가상 일정
  • End Date / Location: 필요할 때 종료 날짜·장소 추가

10/29/2026은 2026년 10월 29일, 10:00 AM은 오전 10시입니다. 열 이름뿐 아니라 각 열에 맞는 값도 확인합니다.

04AI에게 일주일 가상 일정 요청하기

수업에서 사용한 요청

지금부터 일주일 동안의 계획에 대해서 더미 데이터를 작성해줘. 평일은 업무 위주로 하루 3개 이하, 주말은 가족 또는 친구 약속 위주로 하루 3개 이하 만들어줘.

Calendar용으로 이어서 요청하기

Google Calendar로 가져올 CSV로 만들어줘. Subject, Start Date, Start Time, End Time, Description을 영어 그대로 사용해줘. 모두 가상 일정으로 만들고, 먼저 표로 보여줘.

“지금부터”의 시작일을 먼저 확인하고 시작일을 포함한 7일로 정합니다. 교재 예시는 2026년 10월 28일~11월 3일이며, 다시 실습할 때는 그날의 날짜에 맞춥니다.

05표를 검수하고 CSV로 저장하기

Google Sheets 🔗에서 영어 헤더와 일정 데이터를 표로 확인합니다. Sheets의 일주일 가상 일정 🔍

  • 시작일을 포함해 7일이며 하루 3개 이하인가요?
  • 평일은 업무, 주말은 가족·친구 약속인가요?
  • 필수 헤더와 날짜, 시작·종료 시간이 맞나요?
  • Description에 “가상 일정”이라고 표시했나요?

CSV 예시 · 주요 4개 열

Subject,Start Date,Start Time,End Time
업무 회의,10/29/2026,10:00 AM,11:00 AM
가족 점심,10/31/2026,12:00 PM,1:00 PM

실습 파일에는 Description 열도 추가합니다. 확인 후 파일 → 다운로드 → 쉼표로 구분된 값(.csv)을 선택합니다. 일정이 있는 현재 시트가 저장됩니다. 한글이 깨지면 UTF-8 저장·읽기를 확인합니다.

06CSV를 실습용 캘린더로 가져오기

  1. Calendar 오른쪽 위 톱니바퀴 → 설정 → 왼쪽 “가져오기 및 내보내기”를 엽니다. 설정 → 가져오기 및 내보내기 🔍
  2. “컴퓨터에서 파일 선택”으로 CSV를 선택합니다.
  3. 대상을 앞에서 만든 실습용 캘린더로 지정합니다.
  4. 파일명·대상 캘린더를 다시 확인하고 “가져오기”를 누릅니다. CSV 파일·실습용 캘린더 선택 🔍

평소 사용하는 기본 캘린더가 선택되지 않았는지 확인합니다.

07등록된 일정과 중복 확인하기

성공 메시지 뒤에도 Calendar를 열어 실제 결과를 확인합니다. 일주일 일정 가져오기 완료 🔍

  • 일주일치 일정이 모두 들어왔나요?
  • 평일·주말의 일정 종류가 맞나요?
  • 날짜·시작 및 종료 시간·대상 캘린더가 맞나요?
  • 중복된 일정은 없나요?

같은 CSV를 다시 가져와도 기존 일정이 자동 수정되는 것은 아닙니다. 중복될 수 있으니 기존 일정 확인 → CSV 수정 → 중복 여부 확인 → 필요한 경우 다시 가져오기 순서로 진행합니다.

실습 뒤에는 다음 연습에 쓰거나 필요 없는 연습 일정만 정리합니다.

기억할 점
실습용 캘린더 만들기 → 가상 일정 요청 → 표·영어 헤더 검수 → CSV 저장 → 가져오기 → 실제 날짜·시간·중복 확인. 성공 메시지만 보지 말고 등록된 일정을 직접 확인합니다.
